## v0.5.0 — 04.11.2026

### Добавлено

- Mini App, экран «Ещё»: строки раздела «Личное» приходят данными из `/webapp/home/data`
  (t_6d1789bb) — новый раздел больше не требует правки оболочки.
- Архив папки: потолок размера ZIP — `ZIP_MAX_BYTES` (по умолчанию 100 МБ). Выше потолка
  отказ `folder_zip_too_large` с текстом «скачивайте по файлам»; раньше папка на 200 МБ
  занимала 200 МБ в `/tmp` сервера.
- Схема БД: 053 — статья «Прочее (доход)» (свободный текст «получила 15000» больше не падает
  в расходную статью); 054 — корни общих папок и автоматические папки спектаклей на триггере базы.
- Служебное, не для участников: уведомления владельцу через боевого бота; диагностика
  показывает, куда Caddy проксирует `/webapp`, и все обращения за 20 минут; аудит строк
  бюджета и занятости на проде; чтение списка участников из базы для маппинга.

### Изменено

- Бюджет: второго подтверждения крупных сумм больше нет — крупная сумма идёт тем же путём,
  что обычная; бейдж и метки подтверждения убраны из интерфейса и подсказок админа.
- Файлы: квота личного места проверяется тем же запросом, что пишет (`insert ... select`
  плюс `for update` на строке участника) — два одновременных подтверждения больше не
  превышают место вдвоём.
- Mini App: один реестр разделов вместо пяти копий; поведение экранов то же.
- Скрипты: одна функция времени Самары в `_cli` вместо четырёх копий; базовая линия
  мёртвого кода 30 → 25 ключей.
- Бот: отказ tool-api на `/zip` доходит человеку словами сервера (413 → «скачивайте
  по файлам»), а не «папка пуста или недоступна».

### Исправлено

- Mini App: баннер «Сайт недоступен» больше не снимается ответом соседнего запроса
  (маяк `/webapp/boot`, тихий вход `/webapp/auth`). При 5xx и обрыве он остаётся на экране,
  «Повторить» — по нажатию. Это и был красный CI на `webapp` и `webapp-webkit`.
- Mini App: маяк `/webapp/boot` пишет поля одной строкой — переводы строк из запроса
  больше не рвут запись.
- Файлы: `Content-Disposition` собирается одним помощником во всех четырёх местах —
  имена с кавычками и переводами строк не ломают скачивание.
- БД: номера миграций 046/047 были заняты дважды — перенумерованы в 053/054, порядок
  применения по имени файла восстановлен.
- На сервере: участники печатаются по фактическим колонкам (`aliases` нет), дамп
  участников — SQL-файлом.

### Схема и совместимость

- Две миграции, обе аддитивные и идемпотентные: 053 (`insert ... where not exists`),
  054 (`create table if not exists` плюс триггер). Код v0.4.4 на новой схеме работает,
  поэтому откат предыдущим тегом базу не ломает.
- API обратно совместим, новых обязательных полей нет. Появилась одна переменная
  окружения `ZIP_MAX_BYTES` — необязательная, по умолчанию 100 МБ.
