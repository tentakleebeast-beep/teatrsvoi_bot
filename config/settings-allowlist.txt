# Исключения из правила «конфиг только через settings» (R-4, docs/reports/79).
#
# Формат строки: <путь от корня репозитория> <число совпадений> # <причина>
# Путь — файл в services/**, кроме settings.py. Число — сколько чтений окружения
# (os.getenv / os.environ / os.environ.get) осталось в файле. Причина — почему
# исключение живёт: без неё строка не принимается.
#
# Список должен только сокращаться: перевели модуль на settings — уменьшите число
# или уберите строку. Мёртвая запись (файла нет или совпадений меньше) — ошибка.
# Обновить числа: env -u PYTHONPATH .venv/bin/python scripts/check_settings.py --update-allowlist
#
# Пустые чтения здесь не значатся: core.py упоминает os.environ только в докстринге.
