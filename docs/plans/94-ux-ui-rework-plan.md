## Как исполнять (для агента и для cron)

1. Взять **первый шаг со статусом `[ ]`**, выполнить только его.
2. Проверить: `env -u PYTHONPATH .venv/bin/python -m pytest -p no:warnings -o addopts="" -q`,
   `.venv/bin/ruff check .`, `env -u PYTHONPATH .venv/bin/python scripts/check_invariants.py`,
   `env -u PYTHONPATH .venv/bin/python scripts/check_registers.py`,
   `SVOI_WEBAPP_TESTS=1 env -u PYTHONPATH .venv/bin/python -m pytest tests/webapp -q --browser chromium`
   (браузерные — когда шаг меняет страницы).
3. Один коммит на шаг: `feat(webapp): <что> (Ш-NN)`. В этом файле `[ ]` → `[x]`
   и хеш коммита; файл плана — отдельным коммитом `docs(plans): Ш-NN`.
4. Увеличить **Итерацию** на 1 и написать три строки: `Итерация N` / `Сделано: …` / `Дальше: …`.
5. Остановиться. Следующий тик продолжит с первого `[ ]`.

**Правила качества** (`docs/development/26-process-and-git.md` §7a): дефект чинится
классом, а не точкой; каждый новый тест называет требование или дефект; ссылки — только
на существующие файлы; ничего не удалять из старых адресов (редирект, не 404).

**Запреты этого плана** (требования заказчика):
эмодзи в интерфейсе — нет; горизонтального скролла — нет; текста мельче 13 px — нет;
целей меньше 44 px — нет; подсказок «на всякий случай» — нет.
