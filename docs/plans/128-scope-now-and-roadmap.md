## 3. Порядок входа дорожной карты

1. **Сначала** заканчивается текущий проход (Ш-01…Ш-15). Пока правило «дом + вход» не в
   документах и не в реестре, новые домены будут проектироваться по старым противоречиям.
2. **Затем** — уведомления: это единственный домен, который сейчас обрывает процессы
   (напоминания и уведомления участников события) и требует миграций.
3. **Затем** — развитие сценариев, по одной карте на тему.
4. **Файлы для участников и VK** — только после решения владельца, не по умолчанию.
5. **Прод** — отдельной картой и только по команде.
