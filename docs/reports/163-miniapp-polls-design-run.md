## 6. Расхождения (AC-5)

### D1. `org` получает отказ «Опросы ведёт администратор» — дефект

V-088 отвечено «(б) админ и организатор», и карта E8 идёт с этим правом. Факт: право
`poll.manage` есть только у `admin`.

Проверено тремя способами:

- `db/init/065_polls.sql:108–119` — выдаёт `poll.manage` и `poll.results.all` только роли `admin`;
  других миграций с `poll.manage` нет (`grep -rln "poll.manage" db/` → один файл, последняя
  миграция — 065);
- dev-база `svoi` (`select role, capability from rbac_role_capability where capability like 'poll%'`):
  `('admin','poll.manage')`, `('admin','poll.results.all')` — строки для `org` нет;
- стенд и экраны: `/webapp/polls` и `/webapp/polls/edit?poll_id=7` под ролью `org` показывают
  «Опросы ведёт администратор. Право poll.manage есть только у администратора», API отдаёт 403.

Хуже того, текст отказа в `api/polls.py:35`, `pages/polls.py:20–21`, `pages/polls_edit.py:24–25`
утверждает «есть у него одного» — то есть после выдачи права организатору он станет ложью.
Цена: строка `insert into rbac_role_capability … ('org','poll.manage')` в новой миграции,
правка трёх текстов отказа, тест на матрицу прав — **40 минут**.

### D2. `/webapp/polls/edit` без `poll_id` открывает конструктор любой роли — дефект

Замер (`chromium`, 390 px, заголовок `X-SVOI-Role`):

| Роль | Путь | Экран |
|---|---|---|
| `admin` | `/webapp/polls/edit` | конструктор: 1 строка вопроса, «Добавить вопрос», «Отправить» |
| `org` | `/webapp/polls/edit` | то же, отказа нет |
| `troupe` | `/webapp/polls/edit` | то же, отказа нет |
| `master` | `/webapp/polls/edit` | то же, отказа нет |
| `troupe` | `/webapp/polls/edit?poll_id=7` | отказ словами (API отдал 403, оболочка показала) |

То есть экран без `poll_id` (новый опрос) не проверяет право вообще: человек без `poll.manage`
видит и заполняет конструктор, а отказ получает только при сохранении. Это расхождение с
`SCREEN_CAPS` (`webapp.py:335` — `/webapp/polls/edit` под `poll.manage`): оболочка закрывает
экран лишь тогда, когда API вернул 403, а без `poll_id` запроса нет. Цена: проверка права до
отрисовки пустого конструктора (тот же запрос, что делает список) и тест на четыре роли —
**30 минут**.

### D3. Запас подписи «Назад» в макете 2 px — риск, не дефект сегодня

Кнопка «Назад» в вёрстке мокапа — `flex: 0 1 auto` с отступом 14 px: подпись 44.1 px при
внутренней ширине 46.1 px, запас 2.0 px на 320 и 390 px одинаково (числа §4). Обрезки нет,
но запас тонкий: при шрифте крупнее нашего (Telegram на Android) подпись поедет. В живом
Telegram ширину кнопки считает клиент, поэтому это риск мокапа и наших мерок, а не боевого
чата. Цена: отступ 16 px вместо 14 в `poll_ui`/вёрстке — **15 минут**, делать вместе с D1.

### Наблюдение без цены: две сборки одной клавиатуры

«Дальше», «Пропустить»), но подписи и коды `p:*` пишутся в двух местах — правивший одну сторону
забудет другую. Вынесено в наблюдения, карту не требует.
