## 2. Принятые решения

1. **Студия считается одним помещением.** Модель пространств в базе есть, в расчёте окон
   не используется — параллельные мероприятия проработаем отдельно.
2. **Обратная связь — только кнопка или форма.** Свободный текст в чате обращений
   не создаёт: похожие формулировки уводили в репорт.
3. **Тип обращения не угадывается.** В формах его выбирает человек.
4. **Предпросмотр назначения не пишет в базу** без `persist=true`.
5. **Реплика листа финансов — из нативной Google-таблицы**, а не из архивного `.xlsx`:
   это самая свежая версия.
6. **Гранулярность записи в лист — настройка**, а не константа в коде
   (`finance_granularity` + `finance_source_map`).
7. **Сверка переноса — по ID операции** (скрытая колонка R), а не по дате и сумме:
   по ним ручная строка неотличима от операции бота.
8. **Педагоги обязательны на тренинге своей дисциплины**, режиссёр фиксируется фактом
   присутствия («по возможности»).
