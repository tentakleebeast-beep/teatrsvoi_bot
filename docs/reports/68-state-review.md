Классовое решение вместо заплаток: все 25 входных моделей наследуют `ApiIn`
(`services/tool-api/app/main.py`), проверка NUL / длины / NaN — одна на весь API.

обойдёт контракт.

Совместимость: бот всегда передаёт ключ операции и допустимые `policy`; Mini App шлёт
`policy` из `KIND_POLICY` (все значения есть в `POLICIES`).
