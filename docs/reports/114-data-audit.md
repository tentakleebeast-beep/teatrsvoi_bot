### Расхождение, которое надо объяснить до импорта

В поле `period` есть только июль–октябрь, а в `tx_date` встречается 19.12.2026.
Значит есть строки, где месяц периода не совпадает с месяцем даты операции.
Это либо перенос операции в другой период, либо след ручного ввода. При импорте
такие строки нельзя перезаписывать молча — их надо показать отдельным списком.

### Взносы живут не в budget_tx

Блока `dues` в `budget_tx` нет вообще: взносы лежат в отдельной таблице
`dues_charge` (32 строки). Маппинг листа «Взносы студийцев» должен писать туда,
а не в `budget_tx`, иначе взносы задвоятся. Требуется правка маппинга перед
импортом финансов.
