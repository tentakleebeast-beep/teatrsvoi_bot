## 4. Решение в одну страницу

**ADR-13.** У действия один путь записи (обработчик tool-api). Чат, Mini App, скрипт и внешний
канал — оболочки: они вызывают этот путь, не заводят своего API и не проверяют права вместо
сервера. Действие, доступное на экране, обязано быть доступно в чате; исключение — строка
реестра с причиной.

Что это меняет на практике:

* **Для новой работы.** Новая кнопка или экран не появляются без строки в реестре: путь
  записи, право, тест. Обратное тоже верно: маршрут без строки — сирота.
* **Для текущего кода.** Семь действий пишутся больше чем одним путём (З2, З3, З5, П1, Ф1, Ф4,
  Л8) и один маршрут дублирует живое действие (С4). Это не приговор: неделя и интервал —
  разная гранулярность, — но правило требует одного обработчика на пару, а не двух похожих.
  Сегодня у занятости три независимые записи в `availability_hour`.
* **Для планирования.** Порядок работ считается не по «красивости» интерфейса, а по цене
  закрытия разрыва и по числу людей, которые в него упираются.

Отвергнутые варианты (подробно — §9.3 решения): паритет «по каждому интерфейсу» (не на что
опираться), «Mini App — основное место» (нарушает `docs/plans/37`), «всё в чат» (дороже и
хуже для таблиц), «единый фасад `POST /action`» (ломает контракт и права), «генерировать
кнопки из реестра» (нет семантики подтверждения), «чинить по обращениям» (уже пробовали:
6 обрывов процессов, 60 % разборов — один вопрос без ответа).

## 7. Чего не делаем (и почему)

* **Не убираем подтверждение денег, календаря, прав и рассылки** — 3 из 8 фраз с суммой за
  30 дней уже терялись на выборе категории.
* **Не даём агенту пишущих инструментов** — `registry.execute` это запрещает, подтверждение
  остаётся единственным путём записи.
* **Не переводим деньги и расписание на «намерение»** — они отвечают детерминированно,
  дешевле и точнее модели.
* **Не делаем VK вторым фронтом в этих картах** — решение по VK уже принято отдельно
  (`docs/architecture/25` §8, `docs/infrastructure/118`): чат-бот сообщества, экраны по ссылке.
* **Не строим фасад `POST /action` и не генерируем кнопки автоматически** — ломает контракт
  либо даёт 40 кнопок без семантики подтверждения.
* **Не закрываем домен уведомлений** — пять требований и своя архитектура.
* **Не удаляем 42 сироты оптом** — часть из них вход для будущих экранов, часть служебная.
* **Не трогаем порог 0.7, квоты, лимиты и ML для категорий.**
* **Не правим чужие ветки и не архивируем чужие карты** — расхождения по номерам вынесены
  картой `AUD-2` к ревьюеру, а не исправлены у себя.

