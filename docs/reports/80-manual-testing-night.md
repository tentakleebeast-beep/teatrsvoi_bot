# 80. Мануальное тестирование бота в Telegram: ночной прогон

**Дата:** 30.10.2026
**Зачем:** проверить то, что не видно из кода и API — как бот и Mini App ведут себя в
настоящем клиенте Telegram (Desktop и iOS). Автотесты (1141) и вызовы API с выпущенным
токеном покрывают логику, но не `initData`, не WebView и не нажатия.

**Статус:** подготовка. Прогон — по договорённости, ночью, на ноутбуке Виктора.

## 2. Мои ограничения на прогон

1. Снимаю **только окно Telegram** (`app="Telegram"`). Ни `app="screen"`, ни другие окна.
2. Работаю **только в чате бота** и в Mini App, открытом из его кнопки. В список чатов,
   поиск, контакты, настройки аккаунта не захожу.
3. Сообщения людям не отправляю, ничего не удаляю и не пересылаю.
4. Тестовые записи помечаю в статье: `тест-ДД.ММ`. Уборка — только после согласования.
5. Каждый шаг: снимок в `docs/reports/screens/80-<шаг>.png` + проверка в базе или листе.
6. Если снимок показывает что-то личное — не пересказываю и не сохраняю, делаю новый
   снимок в Zen mode.

## 3. Сценарий

Каждый шаг: действие → ожидаемый результат → чем проверяю.

### Шаг 1. Меню и разделы

- [ ] Отправить боту `/start`, снять главное меню

- **Ожидание:** на каждую кнопку — ответ без ошибок, кнопки не «съедаются» формой
- **Проверка:** `journalctl -u svoi-gateway -n 50` без `Traceback`, `/api/health` ok

### Шаг 2. Свободный текст → n8n → ассистент

- [ ] «сколько денег осталось на счету?»

- **Ожидание:** осмысленный ответ, `intent` определяется, нет `provider_unavailable`
- **Проверка:** `docker exec n8n-prod ...` не нужен; смотрим ответ в чате + журнал гейтвея

### Шаг 3. Неделя занятости (Mini App)

- [ ] Кнопка меню → «Открыть неделю»
- [ ] Отметить день как занятый, сохранить

- **Проверка:** `select day, hour, kind from availability_hour where participant_id=<id> order by day desc limit 5`

### Шаг 4. Операция: расход, доход, план

- [ ] «Внести операцию» → расход 1 ₽, статья `тест-ДД.ММ`
- [ ] доход 1 ₽, статья `тест-ДД.ММ`

- **Проверка:** `select id, tx_type, amount, is_plan, purpose from budget_tx order by id desc limit 5`

### Шаг 5. Анкета и карточка участника

- [ ] «Моя анкета» — данные заполнены, не пусто
- [ ] Карточка участника из списка — сведения и сумма взноса

### Шаг 6. Админ-панель и обратная связь

- [ ] Обратная связь: отправить тестовое сообщение

## 6. Что выяснилось на практике (30.10.2026, дневная проба)

Прогон уже частично сделан днём — вот что важно знать до ночи.

- **Снимок окна Telegram ищется по bundle id**, а не по имени: `app="Telegram"`
  даёт «no on-screen window matched», а `app="ru.keepcoder.Telegram"` работает.
  Для окон Qt-приложений надёжнее `pid` + `window_id` из `list_windows`.
- **`CuaDriver.app` надо держать в `/Applications`**: в `~/.hermes/tools/...` его не видно
  в списке «Запись экрана», и разрешение выдать нечем. Копия в `/Applications` решает.
- **Клики по индексам элементов работают только когда окно активно**: у фонового окна
  AX-дерево пустое (0 элементов). Порядок: `click(delivery_mode="foreground")` →
  следующий `capture` уже отдаёт дерево с индексами.
- **Захват иногда отдаёт 0×0** («ScreenCaptureKit … неполадки при захвате») и окна
  пропадают из `list_windows`, хотя приложение работает. Лечится повтором; после серии
  захватов помогает перезапуск драйвера — но тогда нужен и перезапуск Hermes,
  иначе инструмент отвечает «Connection closed».
- **`caffeinate -dimsu` обязателен**: без него дисплей засыпает, и все снимки чёрные.
- **Mini App в Telegram Desktop кэширует страницу**: после выката правок старое окно
  показывает прежнюю версию (у нас — форму без SDK и с «откройте из бота»). Помогает
  только закрыть и открыть заново кнопкой бота.

Проверено днём: неделя занятости в Mini App отрисовалась внутри Telegram —
«26 октября — 01 ноября, отмечено 6 из 7 дней», дни с отметками. Значит SDK и обмен
`initData` на токен работают в реальном клиенте.

Не проверено: форма операции (категории по направлению, запись), анкета, админ-панель.

## 4. Чего в этом прогоне нет

- iOS: с ноутбука не проверить, нужен телефон (отдельная договорённость)
- Нагрузка и несколько одновременных пользователей
- Оплата, VK-канал, рассылки

## 5. Если что-то пошло не так

- Бот молчит: `systemctl status svoi-gateway`, `journalctl -u svoi-gateway -n 30`
- Mini App не открывается: `curl -s https://svoi-theater-samara.online/api/health`,
  `journalctl -u svoi-tool-api -n 30`
- Ошибка в форме: текст теперь человекочитаемый — фиксирую дословно
- Откат не нужен: прогон ничего не меняет в коде, только тестовые данные
