Правила раскладки:

* домен элемента определяется путём маршрута (`/tools/*`, `/webapp/*`, `/admin`,
  `/files`, `/folders`, `/tags`), помощник уходит в домен, если его читает ровно
  один домен, иначе в `core`;
* домены обращаются к общему как `core.ИМЯ`, к соседнему домену — `<домен>.ИМЯ`;
  это позднее связывание через модуль, поэтому циклов импорта нет;
* `configure()` меняет значения в `core`, а домены читают их оттуда, — подмены
  настроек в тестах видны всем модулям без «протаскивания» имён;
* порядок маршрутов внутри домена сохранён; страницы Mini App подключаются
  первыми, их пути не пересекаются с JSON-API.
