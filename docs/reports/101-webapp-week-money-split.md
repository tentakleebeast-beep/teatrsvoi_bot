## Что стало

Разрез по смысловым единицам, а не по строкам: экран ↔ его скрипт ↔ общие куски.

`money.py` (100 строк) — вкладка «Деньги»: `_HEAD`, разметка, `MONEY_PAGE`;
реэкспорт `TX_PAGE`, поэтому `from app.pages.money import TX_PAGE` продолжает
работать (маршруты, стенд, тесты).

| модуль | строк | что держит |
| --- | --- | --- |
| `money.py` | 100 | вкладка «Деньги»: стили, разметка, `MONEY_PAGE`, реэкспорт `TX_PAGE` |
| `money_script.py` | 364 | JS вкладки: операции месяца, бюджет, свои взносы |
| `money_tx.py` | 72 | форма операции: разметка, `TX_PAGE` |
| `money_tx_script.py` | 380 | JS формы: дата, тип, категория, сохранение, «Вернуть» |

`week.py` (90 строк) — сборка недели: `_SEGMENT_WEEK`, разметка, `WEEK_PAGE`,
склейка скрипта из двух частей и реэкспорт `SUMMARY_PAGE`.

| модуль | строк | что держит |
| --- | --- | --- |
| `week.py` | 90 | неделя: разметка, `WEEK_PAGE`, реэкспорт `SUMMARY_PAGE` |
| `week_shared.py` | 35 | общие куски: строка дня (`_day_row`, `_DAYS`), `_WEEK_NAV` |
| `week_marks.py` | 393 | JS недели, ч. 1: строка дня, лист, сохранение, «Вернуть» |
| `week_template.py` | 183 | JS недели, ч. 2: очистка, «Запомнить», шаблон, навигация, запуск |
| `week_summary.py` | 239 | сводка занятости: разметка, JS, `SUMMARY_PAGE` |

Скрипт недели — один `<script>`, он разрезан на две части по смыслу и склеивается
в `week.py`: `_SCRIPT_WEEK = _SCRIPT_WEEK_MARKS + _SCRIPT_WEEK_TEMPLATE`.
Общие `_DAYS`/`_WEEK_NAV` вынесены в `week_shared.py`, чтобы `week.py` и
`week_summary.py` не импортировали друг друга.
