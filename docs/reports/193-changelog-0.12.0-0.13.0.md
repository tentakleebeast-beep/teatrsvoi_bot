# 193. Сводный журнал изменений: v0.12.0 → v0.13.0

Диапазон: тег `v0.12.0` (`2b4d7c6`) → `ce417d3`, 22.11–23.11.2026.
Объём: 87 коммитов (56 без мержей), 172 файла, +19 525 / −2 337 строк, две миграции
(`072_google_event_calendar`, `073_files_two_locations`).
Источник: `CHANGELOG.md` по разделам версий плюс `git log` диапазона.

Главное: три эпика впервые дошли до кода — Google-процесс (E1), файлы (E4), календарь (E5).
Всё это накопилось за два дня и в прод ещё не выкатывалось.

## Google: процесс, права, запись листов (E1)

- **E1-1** — исследование текущего процесса влито: документ 178 (карта по ролям, правила
  чтения и записи, пробник `scripts/probes/schedule_snapshot.py`), вопрос V-112.
- **E1-3** — спецификация 186: контракты процесса Google, реестр объектов, границы записи,
  защита боевых календаря и листов.
- **E1-4** — реализация: реестр объектов, режим и свежесть, «Сверить», протокол записи
  листов, точка входа скриптов, роль сервисного аккаунта по операции, включающее окно
  отчёта, `dry_run` без записи. Запись тестового листа цветов протоколом `schedule.test`.
- **E1-2** — дизайн Google-процесса без ролевых частей (документ 180-й серии), запаркован
  до анкеты.
- **Д-1** — `fill_test_schedule.py --list`, люди из шапки живого листа, источник
  `SCHEDULE_HUMAN_*`.
- **Д-2** — отменённое событие больше не считается живым в черновом календаре.

## Файлы (E4)

- **Дизайн 189** — два расположения файлов, описание, папки, поиск; вопросы V-123…V-125.
- **Спецификация 192** — критерии, форма колонок, квоты, сироты, номера карт-продолжений.
- **Реализация** — два расположения, описание, папки и поиск; владелец в ответе `view`,
  правка описания на карточке, поиск и чипы на экранах, стенд и браузерные тесты.
  Миграция `073_files_two_locations`.
- **Миграция перенумерована 072 → 073**: номер 072 был занят Google-календарём, две
  ревизии с одним id сломали бы `alembic upgrade head`. Голова 072 в тестах миграций
  приведена к факту.

## Календарь (E5)

- **Дизайн 187** — карточка события, сверка календаря, типы и цвета.
- **Спецификация 190** — контракты, экраны, критерии.
- **Решения владельца** — цвет типа приходит из настройки, чужой цвет уходит в отчёт;
  «Перекрасить все» остаётся постоянной функцией и работает в боевом календаре как
  исключение из V-072.
- Реализация начата, в этот диапазон не входит.

## Мини-приложение и бот

- **Главная** — блок «Завтра» и ссылка «Весь календарь» (V-131, обращение №46).
- **Заметки** — удаление своей заметки в Mini App и API, с подтверждением (обращение №46).
- **Лист дня** — время через точку «18.30» принимается наравне с «18:30» (обращение №45).
- **«Что умею»** — строка на право, перехват вопроса до модели, мёртвые права сняты
  (`system.health` у `org`/`troupe`, `quota.manage` у `admin`). Перехват ловит обратный
  порядок слов и «что-нибудь».

## Проекты (E6)

- **Дизайн 191** — модель проекта, связь с событиями и деньгами, правило дохода от аренды.
- **Решения владельца** — статья «Аренда (доход)» вместо «Субаренды»; карточку проекта
  видят только `admin` и `org` по праву `budget.read`; сумма события — единственный источник
  дохода, доплаты и переплаты идут отдельными операциями.
- Спецификация и реализация — следующие карты.
