# 58. Тест-план регрессионного прогона

> **n8n выведен из контура (V-026, 01.11.2026).** Где ниже n8n назван частью контура или
> источником разбора свободного текста, читать: `POST /tools/route` в tool-api
> (`services/tool-api/app/router_llm.py`); воркфлоу, публичный вебхук и переменные `N8N_*`
> удалены из деплоя. История контрактов — `docs/archive/29-n8n-scenarios.md`.

Дата: 27.10.2026. Для случая «внедрили новую функциональность — проверить, что старое
не сломалось». Рассчитан на один прогон за 15–20 минут, без чтения кода.

---

## 1. Уровни и что запускать

| Уровень | Команда | Когда обязателен |
|---|---|---|
| Линтер | `ruff check .` | всегда |
| Юнит (без БД) | `pytest -q tests/unit` | всегда |
| Интеграция (Postgres) | `pytest -q tests/integration` | всегда |
| Инварианты бизнеса | `python scripts/check_invariants.py` | если менялись деньги или занятость |
| Страницы Mini App | `pytest -q tests/unit/test_webapp_pages_js.py` | если менялись страницы |
| Документация | `pytest -q tests/unit/test_docs_links.py` | если менялись docs |
| Роутер n8n | `python scripts/check_router_scenarios.py` | если менялся промпт или маршруты |

Полный прогон одной командой: `pytest -q && ruff check . && python scripts/check_invariants.py`.

## 2. Матрица «что менял → что проверить»

| Изменение | Обязательные проверки |
|---|---|
| Новый эндпоинт | тест happy path + отказ по правам + валидация входа |
| Новое поле в таблице | миграция идемпотентна, тест на сохранение и чтение |
| Изменение модели ролей | `test_roles.py`, `test_admin_panel.py`, регистрация |
| Бюджет (запись, суммы) | `test_budget_*`, инварианты, сверка `reconcile.py --dry-run` |
| Занятость (ввод, импорт) | `test_slots*`, `test_schedule_grid`, проверка «бот не затёрт импортом» |
| События и назначение | `test_events_*`, `test_window_policy`, `test_venues_api` |
| Уведомления | `test_notifications`, проверка `title`/`body` в payload |
| Страницы Mini App | `test_webapp_pages_js`, `test_webapp_*`, ручной просмотр на 390px |
| Тексты бота | `test_gateway_html_safe`, `test_gateway_routing`, `test_text_routing` |
| Промпт / маршруты n8n | `check_router_scenarios.py` (золотой набор 20 фраз) |
| Документы | `test_docs_links.py`, пересборка `build_docs_index.py` |

## 3. Ручной чек-лист после прогона

Пять минут, ловит то, что не видят тесты:

1. `/start` → меню из девяти кнопок, «Обратная связь» на месте.
2. «Бюджет» → суммы совпадают с последним известным балансом.
3. «Расписание» → есть дни, нет пустого сообщения.
4. «Занятость» → кнопки дней, запись появляется в Mini App.
5. «Расход» → сумма, категория, карточка «Записать расход?» с кнопками «Записать»/«Отмена»
   → «Записано: …». Крупная сумма пишется сразу, любой суммы: второго подтверждения нет.
6. Mini App: анкета → сохранить → перечитать; личный лист → отметить час.
7. Форма поиска окон → найти → назначить → событие видно в календаре.
8. «Обратная связь» → отправить → приходит подтверждение, организатору — уведомление.
9. `/feedback` организатором → «Сделано» → автору приходит уведомление с текстом.

## 4. Признаки, что прогон не засчитан

- Тесты зелёные, но `ruff` или инварианты падают.
- Прогон шёл на параллельных процессах без изоляции базы (`duplicate key pg_database_datname_index`).
- Падения «известные» и пропущены без записи в отчёт.
- Изменение затронуло тексты бота, а `test_gateway_html_safe` не запускался.
