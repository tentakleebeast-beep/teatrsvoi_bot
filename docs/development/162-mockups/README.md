# Мокапы E8: опросы в боте

Файлы собраны не руками: их пишет проба `scripts/probes/e8_polls_probe.py` настоящим
каркасом Mini App (`app.pages.layout.page`) с живым CSS проекта, поэтому меряется
настоящая разметка, а не нарисованная картинка.

    env -u PYTHONPATH .venv/bin/python scripts/probes/e8_polls_probe.py

| Файл | Что показывает | Где описан |
|---|---|---|
| `01-builder.html` | конструктор: тема, 11 вопросов, добавление вопроса | `docs/development/162` §6 |
| `01b-builder-compact.html` | тот же экран со строками в одну линию — рекомендованный вариант | §6, пункт 1 |
| `02-audience.html` | адресаты: наборы, люди списком, получатели результатов | §6, пункт 2 |
| `03-chat-question.html` | сообщение-вопрос в чате: три состояния (варианты, свободный ввод, возврат после закрытого чата) | §5 |
| `04-results.html` | сводка по вопросам: да/нет, число, свободные тексты | §6, пункт 3 |
| `05-results-full.html` | сводка на все 11 вопросов анкеты 161 (3 002 px) | §6, пункт 3 |

`.png` рядом — первый кадр 390 × 844, он же приложен к карте.

Правила: мокап — не эталон дизайн-системы (эталон — `docs/development/91-design-system.md`
и справочник компонентов `/webapp/ui`); при расхождении прав документ, а мокап приводится
к нему. Эти файлы живут рядом с документом 162, а не в `prototypes/`, потому что
в `prototypes/` живых макетов нет вовсе (эталон — код).
