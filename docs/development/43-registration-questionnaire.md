# 43. Анкета участника в Mini App

Дата: 27.10.2026. Первый кусок Mini App — не сетка и не бюджет, а **анкета**:
человек сам заполняет то, что иначе пришлось бы выяснять у него в чате.

---

## 1. Зачем анкета

Два поля, которых боту критически не хватает и которые никто, кроме самого человека,
не знает точно:

| Поле | Зачем |
|---|---|
| **Время в пути** | окна считаются с дорогой: у одного 15 минут, у другого час |
| **Роли по спектаклям** | запрос «окна для Наташи и Сэма в Жизни насекомых» должен находить людей |

Плюс третье, побочное: анкета приучает человека к Mini App на простом действии,
до того как он увидит сетку занятости.

---

## 2. Как это работает

```
бот → кнопка web_app → Telegram открывает WebView
        │
        ├── страница /webapp (одна HTML, без сборки)
        │
        ├── JS берёт window.Telegram.WebApp.initData
        │
        ├── POST /webapp/auth  {init_data}
        │      проверили HMAC → выдали токен на 30 минут
        │
        ├── GET /webapp/profile → текущие значения + список спектаклей
        │
        └── POST /webapp/profile {travel_minutes, roles}
               сохранили, записали в аудит
```

Авторизация — по официальному алгоритму Telegram:

```
secret = HMAC_SHA256("WebAppData", bot_token)
hash   = HMAC_SHA256(secret, data_check_string)
```

Дополнительно проверяется `auth_date` — данные старше часа не принимаются.

---

## 3. Что хранится

| Поле | Где | Почему там |
|---|---|---|
| Время в пути | `participant.travel_minutes` | характеристика человека, одна на всех |
| Роль | `person_alias` (`alias_kind='role'`, `project_id`) | роль — псевдоним человека внутри спектакля (docs/architecture/41) |
| Спектакли на выбор | `project` | общий справочник |

Роли при сохранении **заменяются целиком**: присланный список считается правдой.
Так повторные сохранения не накапливают мусор — иначе через месяц у человека
будет пять «Наташ» из пяти попыток.

Несколько ролей в одном спектакле разрешено: «Наташа» и «Нянюшка» — две строки
с одинаковым `project_id`. Это ровно тот случай, о котором говорил заказчик.

## 4. API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/webapp` | страница анкеты (HTML) |
| POST | `/webapp/auth` | `init_data` → токен на 30 минут |
| GET | `/webapp/profile` | анкета + проекты |
| POST | `/webapp/profile` | сохранить `travel_minutes` и `roles` |

Ошибки, которые возвращаются явно:

| Ситуация | Ответ |
|---|---|
| Подпись не сошлась | `401 bad_signature` |
| Данные старше часа | `401 expired` |
| Токен истёк | `401 token_expired` |
| Человека нет в базе | `200 {ok:false, error:"not_registered"}` с текстом для человека |
| Участник в архиве | `200 {ok:false, error:"archived"}` |
| Время в пути вне 0–240 | `400 travel_minutes_out_of_range` |

Отдельно: незарегистрированный **не получает токен**, но получает понятный текст
«Сначала зарегистрируйтесь в боте по коду приглашения» — а не пустой экран.

## 5. Пока нет HTTPS: команда `/profile`

Mini App требует HTTPS, а до переезда на сервер бот работает локально.
Поэтому в чате есть запасной путь — тот же смысл, проще форма:

```
/profile
→ Анкета: Иванов Виктор
   Дорога до театра: 60 мин
   Роли: Наташа — Жизнь насекомых

   Изменить дорогу: /profile 45
   Роли заполняются в анкете Mini App (появится после переезда на сервер).

/profile 45
→ Записал: дорога до театра 45 мин. Окна теперь считаются с этим временем.
```

Что можно из чата: посмотреть анкету и поменять время в пути.
Что нельзя: заполнить роли — их список требует выбора спектакля из справочника,
в чате это превратилось бы в переписку на пять сообщений.

Почему время в пути правится текстом, а роли нет: число проверить легко
(0–240 минут), а роль без спектакля бессмысленна — нужен справочник.

---

## 6. Как открыть

**В проде:** кнопка `web_app` в сообщении бота, URL `https://<домен>/webapp`.
Telegram требует HTTPS — до переезда на сервер (docs/infrastructure/35) кнопка работать не будет.

**Локально:** `http://127.0.0.1:8000/webapp?dev_token=<токен>`.
Токен выдаётся так:

```bash
curl -s -X POST http://127.0.0.1:8000/webapp/auth \
  -H 'Content-Type: application/json' \
  -d '{"init_data":"..."}'
```

Параметр `dev_token` — временный, при `ENV=prod` его нужно убрать из страницы.

## 7. Тесты

`tests/unit/test_webapp_auth.py` — 9 тестов: валидная подпись, подделанная подпись,
чужой токен бота, просроченные данные, пустой ввод, выдача и проверка токена,
чужой секрет, истечение токена, мусор вместо токена.

`tests/integration/test_webapp_profile.py` — 7 тестов: авторизация и чтение анкеты,
сохранение времени в пути, сохранение и замена ролей, несколько ролей в одном
спектакле, отказ без токена, отказ незарегистрированному, проверка границ.

`tests/integration/test_profile_api.py` — 4 теста на чат-вариант:
чтение своей анкеты, правка времени, границы 0–240, чужая анкета недоступна.

Всего 20 тестов, все на реальной БД `svoi_test`.
