# Архив документации

Здесь лежат документы, которые **не действуют**. Их читают, чтобы понять, почему решение
принято именно так, — но код, тесты и новые документы на них не опираются.

## Что попадает в архив

1. Документ описывает то, чего в коде больше нет: выведенный из контура n8n (V-026),
   отменённые маршруты, снятые экраны.
2. Документ заменён новым и противоречит ему (старая дизайн-система, прежняя навигация).
3. Датированный срез, который уже не отвечает на вопрос «как сейчас»: чекпойнты
   и смоук-отчёты старше текущего релиза.

Не попадает в архив: датированный отчёт, на который ссылаются как на основание решения
или как на источник находок (`docs/reports/79`, `84`, `104`). Такой отчёт остаётся
на месте и получает в шапке строку «находки закрыты — где».

## Как переносить

1. `git mv docs/<группа>/<номер>-<имя>.md docs/archive/<номер>-<имя>.md`.
   **Номер не меняется** — сквозная нумерация не переиспользуется.
2. В первую строку файла — пометка в одном формате:

   ```
   > **Архив.** Заменён: `docs/development/108-agent-mode.md`. Причина: n8n выведен из контура (V-026, 01.11.2026).
   ```

   Три части обязательны: что заменило, почему, с какого решения. Если замены нет
   (отменённая идея), пишется решение, которое её отменило.
3. Ссылки на переехавший документ по всему репозиторию правятся на `docs/archive/<номер>-<имя>.md`.
4. `env -u PYTHONPATH .venv/bin/python scripts/build_docs_index.py` — индекс пересобирается,
   архив в нём отдельной строкой в конце.
5. Проверка: `env -u PYTHONPATH .venv/bin/python -m pytest -p no:cacheprovider -q tests/unit/test_docs_links.py`.

## Как ссылаться

* Из действующего документа: `история решения — docs/archive/38-approvals.md`.
  Так читатель сразу видит, что это история, а не правило.
* Не ссылаться из кода и тестов: если код объясняет себя архивным документом, значит
  правило живёт только в истории, — нужно действующее место.
* Восстановить документ из архива можно, только если решение отменено снова:
  тогда он возвращается в группу по смыслу с прежним номером и шапкой «Возвращён: почему».
