## 2. Что появилось вне плана

| Появилось | Почему |
|---|---|
| **RBAC + capabilities** | реальность: владелец — админ, организатор, студиец и педагог одновременно; одна роль не описывала доступ |

## 3. Что осталось — по приоритету

### Ближайшее (без этого бот не «рабочий инструмент»)

1. **Идемпотентность записи** — ключ `(chat_id, message_id)` или хеш черновика; сейчас двойной клик = двойная запись.
2. **Регрессивный пересчёт бюджета** — запрошен заказчиком: пересборка периода из файла/БД с пересчётом итогов и накоплений.
3. **Двусторонняя сверка** — чтение месячных листов и сведение с БД (`reconcile`), расхождения → `Проверки`.
4. **Поиск окон top-3** — главный сценарий для заказчика после бюджета.
5. **Заметки и файлы** — закрыть `notes.write` / `files.access` (с учётом ограничения service account).
6. **Квоты для router-ветки** — сейчас ответ LLM через n8n обходит `llm_policy`; нужно списывать расход по `engine=n8n-openrouter`.

### Среднее

7. Календарь: `CALENDAR_ID`, создание событий по подтверждению, отмена.
8. Уведомления: напоминания T−24/T−2, `payment_due`, дайджест, тихие часы 20:00–08:00.
9. Факт-валидатор ответов: сверка чисел/дат/имён с `source` перед отправкой.
10. Тесты: сейчас **нет ни одного** (`pytest` не подключён); нужны контрактные тесты `tool-api` и парсеров.
11. `docker compose up` как единый способ запуска (файл есть, не проверен).

### Позже

12. Аналитика «сколько стоит спектакль», `budget/query` с агрегатами.
13. Групповые чаты, опрос доступности рассылкой, парсинг выписок.
14. Перенос n8n на VPS, webhook вместо polling, прод-контур (`docs/infrastructure/08`).

## 4. Отклонения от первоначальных решений

| Было | Стало | Причина |
|---|---|---|
| SQLite для старта | Postgres 16 с первого дня | заказчик: без временных протезов |
| Одна роль на человека | множественные роли + capabilities | реальные роли пересекаются |
| Порог второго подтверждения 50 000 ₽ | 100 000 ₽ | уточнено заказчиком |
| Тихие часы 22:00–09:00 | 20:00–08:00 МСК+4 | уточнено заказчиком |
| AI Agent node в n8n | HTTP Request + credential `openRouterApi` | агентная нода в 2.44.6 не публикуется/не исполняется при импорте |
| LLM-ключ в `.env` | ключ остаётся в n8n | ключ из credential недоступен другим сервисам |
| «Вложения» в показах = доход | расход | ошибка классификации, исправлена |
| Перенос периодов для авансов | кассовый метод + `service_period` | «аванс в октябре — октябрьский доход», важна консистентность баланса |
